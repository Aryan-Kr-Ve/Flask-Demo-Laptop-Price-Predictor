How a spec becomes a price

  1. 1

    Describe the machine

    Brand, form factor, CPU/GPU, RAM, storage, display size and resolution — the same fields a spec sheet lists.

  2. 2

    Engineered features are derived

    Screen size and resolution are converted to pixels-per-inch, the field the model actually learned pricing patterns from.

  3. 3

    The ensemble reads it back

    A stacking/voting regressor — the strongest of ten models tested — returns a price on a log scale, converted back to rupees.
